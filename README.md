# 📝 Formulário HTML

Estrutura de formulário desenvolvida utilizando apenas HTML, com foco na marcação semântica e organização dos campos de entrada.

## 🚀 Funcionalidades

* Estrutura de formulário para coleta de dados
* Utilização de diferentes tipos de inputs HTML
* Organização semântica com labels e campos associados

## 🛠️ Tecnologias Utilizadas

* HTML5


## ▶️ Como Executar
